# Redesign Visual — Palpitômetro Copa 2026

**Data:** 2026-05-27
**Projeto:** Palpitômetro v1
**Status:** Aprovado

---

## Objetivo

Substituir os emojis de bandeira por escudos reais das seleções e aplicar um design dark premium com tema azul elétrico em todas as telas do app.

---

## Abordagem

Criar um sistema de design com tokens centralizados (`theme.js`) e extrair componentes visuais reutilizáveis em arquivos separados. A lógica de estado e dados permanece em `App.js`; apenas o visual é refatorado. Escudos servidos via mapa estático de URLs (`src/data/crestUrls.js`) pré-resolvidas da thesportsdb.com — zero requisições em runtime.

---

## Componentes

### TeamCrest

Props: `team` (string), `size` (number, default 32)

- Lê URL de `CREST_URLS[team]` do mapa estático
- Renderiza `<img>` com `object-fit: contain` e `width/height = size`
- `onError`: oculta img (mostra nada — o nome do time já está presente)
- Fallback se URL ausente: emoji `FLAGS[team] || "🏳️"` com `fontSize: size * 0.7`

### MatchCard

Props: `match`, `hVal`, `aVal`, `onH`, `onA`, `disabled`, `pts`

Layout horizontal:
```
[TeamCrest 40px] [nome time] [input 44px] – [input 44px] [nome time] [TeamCrest 40px]
```

- Card: surface glassmorphism, `border-radius: 12px`
- Header interno: grupo + rodada + data em texto muted 10px
- Inputs: `44×44px`, fonte 22px bold, centralizada; borda azul em foco (`rgba(59,130,246,0.5)`)
- Estado desabilitado (resultado real): inputs read-only, fundo levemente mais escuro
- Badge de pontos: canto superior direito, círculo 20px — verde (+3), azul (+1), vermelho (+0)
- Borda do card muda para `borderHover` quando tem resultado

### GroupCard

Props: `groupKey`, `groupData`, `predictions`, `results`, `participantId` (null = modo resultados/admin), `onMatchChange`, `disabled`

- Header: "Grupo A" bold + 4 `<TeamCrest size={24}>` em linha + seta expansível
- Corpo (colapsável): lista de MatchCards do grupo
- Fundo glassmorphism; borda azul `rgba(59,130,246,0.15)`

### LeaderboardRow

Props: `rank`, `participant`, `points`, `totalMatches`, `predictedMatches`, `isCurrentUser`

- Badge de posição: círculo 28px — dourado (#1), prata (#2), bronze (#3), cinza (demais)
- Avatar: círculo 36px com inicial do nome, cor derivada do ID do participante
- Nome: texto 14px bold
- Pontos: texto 18px bold azul `#3B82F6`
- Barra de progresso: largura proporcional ao máximo de pontos do grupo, cor azul
- Card do usuário atual: borda `rgba(59,130,246,0.5)` + leve glow azul

### SectionHeader

Props: `title`, `subtitle?`, `action?` (ReactNode)

- Título: 11px uppercase, letter-spacing 1.5px, cor `sub`
- Divider: linha `rgba(255,255,255,0.06)` abaixo
- `action`: alinhado à direita (ex: botão "Ver todos")

## Fonte dos Escudos

**thesportsdb.com** — API gratuita, sem autenticação.

Endpoint para buscar URL do escudo por nome do time em inglês:
```
https://www.thesportsdb.com/api/v1/json/3/searchteams.php?t=Brazil
→ response.teams[0].strTeamBadge
```

O arquivo `src/data/crestUrls.js` é gerado uma vez com um script Node e commitado. Formato:
```js
export const CREST_URLS = {
  "Brasil": "https://www.thesportsdb.com/images/media/team/badge/...",
  "Argentina": "https://...",
  // ...48 seleções
};
```

O script de geração (`scripts/fetch-crests.js`) faz as 48 requisições, resolve os nomes PT→EN via mapa, e escreve o arquivo. Roda uma vez, resultado commitado.
