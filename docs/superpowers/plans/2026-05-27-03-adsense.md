# Google AdSense Integration Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrar corretamente o Google AdSense com slots funcionais na HomeView e um banner fixo no rodapé, sem erros em desenvolvimento e pronto para ativar quando a conta for aprovada.

**Architecture:** Um componente `AdSlot` encapsula a lógica do `adsbygoogle.push()` via `useEffect`. O Publisher ID fica em variável de ambiente. Em desenvolvimento (sem o script do AdSense carregado), o componente renderiza um placeholder visual e não gera erros.

**Tech Stack:** Google AdSense, React 19, variáveis de ambiente `REACT_APP_*`

## Task 3: Criar componente `AdSlot`

**Files:**
- Create: `src/components/AdSlot.jsx`

- [ ] **Criar `src/components/AdSlot.jsx`**

```jsx
import { useEffect, useRef } from "react";

/**
 * Renderiza um slot do Google AdSense.
 * Em desenvolvimento (sem o script carregado), exibe um placeholder.
 * Aceita os mesmos formatos do AdSense: "auto", "horizontal", "rectangle".
 */
export function AdSlot({ slot, format = "auto", style = {} }) {
  const ref = useRef(null);
  const client = process.env.REACT_APP_ADSENSE_CLIENT;
  const isDev = !client || client.includes("SEU_PUBLISHER");

  useEffect(() => {
    if (isDev || !window.adsbygoogle) return;
    try {
      (window.adsbygoogle = window.adsbygoogle || []).push({});
    } catch (e) {
      // Slot já inicializado — ignora
    }
  }, [isDev]);

  if (isDev) {
    // Placeholder visual em desenvolvimento
    const heights = { auto: 90, horizontal: 90, rectangle: 250 };
    const h = heights[format] || 90;
    return (
      <div style={{
        height: h, background: "rgba(255,255,255,.03)", border: "1px dashed rgba(255,255,255,.1)",
        borderRadius: 8, display: "flex", alignItems: "center", justifyContent: "center",
        color: "rgba(255,255,255,.2)", fontSize: 11, fontFamily: "monospace",
        ...style,
      }}>
        AdSense [{format}] — slot: {slot || "não configurado"}
      </div>
    );
  }

  return (
    <ins
      ref={ref}
      className="adsbygoogle"
      style={{ display: "block", ...style }}
      data-ad-client={client}
      data-ad-slot={slot}
      data-ad-format={format}
      data-full-width-responsive="true"
    />
  );
}
```
